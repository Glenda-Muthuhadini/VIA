South African catalogue. Source URLs and verification dates are stored with each
record, requirement, application cycle and relationship. Older intake information
is explicitly identified instead of being relabelled as current admissions data.

Residence prices are published starting rates, not live quotations or confirmed
availability. Distances remain NULL. Provider accreditation claims are not treated
as independent NSFAS verification, so compatibility remains NULL. No stock image
is represented as a property photograph; the UI supports source-provided image
URLs and displays an icon when none is stored. Institution logos are also optional.

Only verified fee values are stored; NULL is never converted to R0. Subject
levels are retained literally rather than inventing a percentage conversion.
Requirements shown in VIA are partial published information, not a complete
admissions rules engine. Recheck official sources for each intended intake year.
